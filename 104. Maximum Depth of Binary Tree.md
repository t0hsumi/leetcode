# step 1

再帰DFS。ノードの数が最大で10^4なのでrecursionlimitの値によってはRecursionErrorになる。
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

非再帰DFS
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        nodes_and_depths = [(root, 1)]
        max_depth = 0
        while nodes_and_depths:
            node, depth = nodes_and_depths.pop()
            if node.left is None and node.right is None:
                max_depth = max(max_depth, depth)
                continue
            if node.left is not None:
                nodes_and_depths.append((node.left, depth + 1))
            if node.right is not None:
                nodes_and_depths.append((node.right, depth + 1))
        return max_depth
```

BFS。子ノードがNoneでないことを確認しを追加する処理を関数化してもよい。このサイズと条件なら
なくてもいいかと思ってしなかった。
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        depth = 0
        nodes_in_depth = [root]
        while nodes_in_depth:
            nodes_in_next_depth = []
            for node in nodes_in_depth:
                if node.left is not None:
                    nodes_in_next_depth.append(node.left)
                if node.right is not None:
                    nodes_in_next_depth.append(node.right)
            nodes_in_depth = nodes_in_next_depth
            depth += 1
        return depth
```

nをノードの数として、
- time complexity: O(n)
- space complexity
    - 再帰DFS: O(1)
    - 非再帰DFS, BFS: O(n)

非再帰DFS, BFSにおいて、root(およびnode)がNoneかの確認を関数冒頭にした。
ループ内でstackなりqueueに入れる前にNoneかのチェックをしているためこうなっている。
取り出してからNoneかを確認することも可能。その場合、一つ前のdepthが最大値みたいになりそう
だったので、データ構造にノードを入れる前に確認した。

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        nodes_and_depths = deque([(root, 1)])
        max_depth = 0
        while nodes_and_depths:
            node, depth = nodes_and_depths.popleft()
            if node is None:

上から配る再帰
```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        max_depth = 0

        def max_depth_helper(node: Optional[TreeNode], depth: int) -> None:
            if node is None:
                return
            nonlocal max_depth
            max_depth = max(max_depth, depth)
            max_depth_helper(node.left, depth + 1)
            max_depth_helper(node.right, depth + 1)

        max_depth_helper(root, 1)
        return max_depth
```
